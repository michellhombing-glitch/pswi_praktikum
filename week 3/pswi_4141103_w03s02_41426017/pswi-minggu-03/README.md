PERTANYAAN LAPORAN ?
1. Mengapa telepon bukan kuantitas number?
Nomor telepon termasuk data identitas, bukan data untuk perhitungan matematika. Karena itu, lebih tepat menggunakan tipe data string/text, supaya angka seperti 0 di awal tetap tersimpan.

2. Apa beda label pilihan dan legend kelompok?
Label pilihan menjelaskan masing-masing pilihan yang bisa dipilih user. Sedangkan legend kelompok memberikan keterangan atau judul untuk satu kelompok pilihan yang memiliki hubungan.

3. Apa beda id dan name?
id digunakan sebagai identitas unik suatu elemen dan biasanya digunakan untuk mengakses elemen tertentu. Sedangkan name digunakan untuk mengelompokkan atau mengidentifikasi data yang akan dikirim saat form diproses.

4. Apa yang terjadi pada checkbox tidak dicentang?
Checkbox yang tidak dicentang biasanya tidak mengirimkan nilai ke server ketika form di-submit. Artinya, sistem akan menganggap user tidak memilih opsi tersebut.
